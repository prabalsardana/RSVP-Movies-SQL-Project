# RSVP Movies – SQL Data Analysis Project

This project focuses on analyzing movie industry data using **MySQL**. It involves creating and managing relational database tables for movies, directors, and ratings, followed by SQL queries to extract meaningful insights.

The project demonstrates practical SQL skills, including database creation, table relationships, JOIN operations, filtering, sorting, aggregate functions, and data analysis.

### Key Features
- Created a relational database using MySQL.
- Designed tables for Movies, Directors, Movie_Director, and Ratings.
- Inserted sample movie industry data.
- Retrieved movies released after 2017.
- Identified the highest-revenue movie.
- Filtered movies based on ratings.
- Connected movies with their respective directors using JOINs.
- Calculated movie profits using revenue and budget.
- Analyzed average ratings by genre.
- Retrieved top-rated movie records.

### Tools & Technologies

### Concepts Practiced
- CREATE DATABASE & CREATE TABLE
- INSERT INTO
- SELECT & WHERE
- ORDER BY & LIMIT
- INNER JOIN
- GROUP BY
- Aggregate Functions (AVG)
- Foreign Keys and Relational Database Design

**Objective:** To strengthen fundamental SQL skills through a practical movie database project and develop the ability to extract meaningful insights from structured data.
